# Edward Night — Resume Presentation

A simple 9-slide React website based on the [GitHub portfolio README](https://github.com/moonman89/moonman89).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Navigation

- **Next:** → ↓ Space
- **Previous:** ← ↑
- **Jump:** Click dots at the bottom
- **First / last:** Home / End

## Build

```bash
npm run build
npm run preview
```
